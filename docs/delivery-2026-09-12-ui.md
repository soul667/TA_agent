# UI 优化交付说明（2026-09-12 · UI 迭代）

范围：`frontend-vue/` 全部页面与组件（Element Plus 2.9 组件库已在用，本次是**设计系统 + 响应式重构**，
不改任何业务逻辑与 API 调用），构建产物已同步发布到 `frontend/`。

## 1. 全局设计系统（`src/style.css`）

- **设计令牌**：品牌色（靛蓝 #4f6ef2 + 墨绿点缀）、文本三级色、圆角（8/12/16px）、三级阴影、
  代码面板 Catppuccin 变量统一到 `:root`，页面背景改为固定柔光渐变。
- **Element Plus 覆写**：卡片圆角/边框/阴影、按钮（主按钮渐变 + 悬浮投影）、标签圆角、
  表格表头与行悬浮、抽屉/弹窗圆角、输入框圆角、步骤条字重，全部对齐同一套令牌；
  Element Plus 变量（`--el-border-radius-base`、`--el-text-color-*` 等）一并语义化。
- **可访问性**：`:focus-visible` 焦点环、正文对比度提升；移动端输入框字号 16px（避免 iOS 聚焦缩放）。
- 新增细滚动条样式（WebKit/Firefox）、`viewport-fit=cover` + `theme-color`（`index.html`）、
  吸底栏 `env(safe-area-inset-bottom)` 安全区适配。

## 2. 断点约定（本次统一）

| 宽度 | 布局 |
|---|---|
| `< 768px` | 单列；答题页代码在前、题目在后；吸顶工具条 + 吸底操作栏；表格一律换成卡片列表 |
| `≥ 768px` | 答题页左右两栏（代码 10/24 固定吸顶，题目 14/24 滚动）；表格布局 |

> 答题页分栏断点由原来的 `md`（≥992px）改为 `sm`（≥768px），与 CSS 中 sticky 的
> `min-width:768px` 对齐。此前 768–991px 区间（小平板 / 分屏窗口）会出现「两栏 CSS 生效但栅格未分栏」
> 的错配，现已一致。手机端「代码置顶顺序阅读」的约定保持不变（代码面板限高 38vh，>16 行时可展开）。

## 8. 第四轮（去彩色 / 单色化，`/adhd` 发散后收敛）

问题：界面虽已极简，但仍有多组高饱和色同屏（品牌靛蓝 + 成功绿 + 警告黄 + 危险红 +
Catppuccin 六色语法高亮），观感廉价。用 ADHD 方法（5 个隔离认知框架并行发散 → 打分聚类 →
3 个聚焦分支深化）收敛出一条主轴：**全站只留一个强调色 + 一个事故红，其余状态全部用墨阶
（字重 + 不透明度）表达**。

**色彩系统（`style.css`）**
- 新增墨阶 `--aa-ink-1/2/3`（浅色 100%/62%/40%，深色 100%/72%/46%），全站状态一律映射到墨阶。
- Element Plus 语义色并入墨阶：`--el-color-success` / `--el-color-warning` → 灰（`#6e6e73` /
  `a1a1a6`），`--el-color-danger` 收敛为唯一事故红（浅 `#d93025`、深 `#ff453a`）。
- 唯一强调色（品牌靛蓝）白名单：主按钮、选中控件、链接、当前题号、进度条、输入聚焦、
  选中项左竖条；白名单之外一律灰阶。
- 语义规则：**正常状态不声明**（不上色、多数列留空），只有"需要行动/异常"才显形；
  红只用于真实事故（提交失败、评价失败、超时未提交、错误提示）。

**代码面板（最大的一片彩色）**
- 删除 `highlight.js/styles/atom-one-dark.css` 引入与全部彩色 `:deep()` 规则，改为单色相墨阶：
  关键字 600 字重、字符串/注释斜体、注释降为 45% 不透明、数字 tabular-nums，色相为零。
- 面板底色改为中性：浅色模式 `#faf9f7`（哑光纸）+ hairline 边框，深色模式 `#101012`（墨）。
- 行状态改三条正交通道：底色（引用行 / 聚焦行）、左侧 2px 竖条（引用=中性灰、聚焦=靛蓝）、
  变更标记（改行实心条、原行删除线 + 灰徽标）；行号栏背景跟随行底色（修掉横向滚动时行号
  底色与行状态不一致的问题）。

**答题页**：选项选中由"蓝色填充"改为"左竖条 + 6% 明度底 + 字重 500"，字母键选中时加深加粗
（不染蓝）；变异题标签由绿字改为深墨 + 「▍」前缀；倒计时去掉黄→红渐变，改为
"常规灰 → ≤5 分钟加深加粗 → ≤1 分钟唯一红 + 1.6s 呼吸"（`prefers-reduced-motion` 下降级）；
进度条不再在完成时转绿。

**结果页 / 教师面板**：状态文字全部墨阶化（等待=灰、完成=中墨、需关注=深墨、失败=红）；
教师表格改"例外驱动"——正常行不再着色，只有"需要 TA 复核 / 评价失败"的行显示
左侧 2px 竖条 + 极淡底（新增 `isAlertRow` / `rowClass`），移动端列表同规则；
统计数字去掉黄色强调；知识点状态与代码质量改用字重区分。

**验证**
- 自动化彩色审计（遍历可见元素的计算样式，统计"非灰阶且非品牌靛蓝/事故红"的颜色）：
  答题页仅剩 1 处——题干行内代码使用的品牌深靛蓝（属强调色家族），其余全部灰阶。
- 浅/深 × 中/英 × 桌面/移动 复验：答题页（代码单色高亮、行状态、选中竖条）、
  教师面板（例外行）、深色移动端；无横向溢出。
- `uv run pytest` 75 passed。

陷阱记录（发散阶段被否决的方向）：动态"颜色竞拍/央行配额"（实现复杂、行为不可预期）、
CI 色彩登记制与硬编码账本（对当前规模过重）、四态形状编码（需用户学习、表格空间不足）、
答对答错完全去红绿（教学反馈效率下降）。

## 9. 第五轮（按评审：行内代码修复 + 选中态去蓝）

1. **题面行内代码显示修复**（`FormulaText.vue` + `StudentExam.vue` / `TeacherPanel.vue`）
   - 原因：后端题面把代码表达式包在 `$…$` 里（如 `$i <= n$`），旧渲染一律按"数学"输出
     Times 斜体，看起来完全不像代码；而 `arr`、`n` 这类标识符后端根本没标记，直接以正文
     字体出现，同屏字体混乱（英文题面尤其明显）。
   - 现在：`FormulaText` 支持 `code-tokens` 属性；页面从本题代码中提取标识符（正则取词，
     排除 C 关键字），题面与选项里整词命中即渲染为等宽 `.ft-code`；`$…$` 内容含
     运算符/括号/下标或命中标识符时也按代码渲染，只有纯符号/变量才保留衬线斜体。
   - 样式：行内代码改为"等宽 + 继承文字色"（不再染品牌蓝、不加底色），与正文靠字形区分，
     不会再看成超链接。教师详情抽屉的诊断/题面/选项/评价反馈同样接入。
2. **选中态去蓝（"左侧蓝色廉价"）**
   - 选项选中：移除 2px 靛蓝左竖条与蓝色浅底，改为中性 6% 明度底 + 字重 500，选中由
     radio/checkbox 控件本身表达（不再有彩色条块）。
   - 代码面板聚焦行：左竖条由靛蓝改为墨色（`--aa-ink-1`），引用行保持中性灰条；
     当前行仍比引用行深一档底色，三态依旧可辨且完全单色。
   - 题目聚焦：题号由"变蓝"改为加深加粗（墨色）。

验证：中文/英文题面 + 选项 + 代码面板聚焦行截图核验；`uv run pytest` 75 passed。
